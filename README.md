# Softy Pinko — React & SCSS Landing Page

Softy Pinko is a modern, responsive React.js landing page designed for business and digital marketing websites. It features a pink-purple gradient hero section, pricing tables, testimonials, and smooth scroll-triggered animations.

**[Click here to preview the website](https://engy2003.github.io/softy-pinko-react/)**

### ✨ Key Enhancements & Customizations

- **Scroll-Triggered Animated Counters:** Built a custom `IntersectionObserver` and `requestAnimationFrame` counter that animates from `0` whenever the section enters the viewport.
- **Responsive Grid & Navbar Fixes:** Updated the navigation bar and testimonial cards using Flexbox and CSS Grid for clean alignment across all screen sizes.
- **Mobile Overflow & Animation Tuning:** Eliminated horizontal scrolling on mobile screens and calibrated AOS scroll animations.
- **Developer Attribution:** Updated footer and project credits.

### 🛠️ Tools Used

- React.js (Hooks)
- React-Bootstrap
- AOS Library for Animation
- Boxicons for Icons
- HTML5 & SCSS
- JavaScript (ES6+)
